# NURHAYO TEXTILE — Rasmiy veb-sayt

NURHAYO TEXTILE trikotaj va to'qimachilik majmuasining zamonaviy korporativ veb-sayti (landing page).

## 📌 Xususiyatlari
- Moslashuvchan va zamonaviy dizayn (Tailwind CSS)
- Mahsulotlar katalogi va toifalar bo'yicha saralash (Filtr)
- **Telegram Bot bilan integratsiya qilingan buyurtma formasi**
- Ikki xil rejimda Telegramga yuborish: To'g'ridan-to'g'ri (frontend) yoki PHP orqali (backend)

## 🤖 Telegram Bot sozlash
Telegram botni ulash bo'yicha to'liq qo'llanma: [TELEGRAM_QOLLANMA.md](TELEGRAM_QOLLANMA.md) faylida keltirilgan.
Qisqacha:
1. `telegram.js` faylini oching.
2. `TELEGRAM_CONFIG` obyektiga `@BotFather` dan olingan `botToken` va `@userinfobot` dan olingan `chatId` ni yozing.
3. Formadan yuborilgan arizalar avtomatik tarzda Telegramingizga keladi!
